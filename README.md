# KathaSync Android — Voice-to-Text SaaS (Android App)

Companion Android app for [KathaSync](https://kathasync.com), a voice-to-text SaaS for Bangla, English, and Banglish. Covers transcripts, notes, summaries, and meeting minutes on the go, with an Android Overlay Service for background capture, phone OTP login, and sync against the KathaSync Supabase backend.

**Tech:** Flutter 3, Dart, Riverpod, GoRouter, Supabase, Android Overlay Service

**Live (web):** [kathasync.com](https://kathasync.com)
**Android build:** [kathasync-mobile-releases](https://github.com/MS-Jahan/kathasync-mobile-releases) (signed APK downloads)

Source is private (personal production app) — this page is a showcase only. Not currently distributed via Google Play Store; distributed as a direct APK with in-app update checks instead.
